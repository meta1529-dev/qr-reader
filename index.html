QRリーダー（画像から）

写真やスクリーンショットの中のQRコードを読み取って、リンクや文字列を表示します。

🔒 画像と読み取り結果は端末の外に送信されません。読み取りはすべてこの端末の中（ブラウザ内）で処理されます。このページ自体のファイルを GitHub Pages から読み込む以外の通信はしません。
✓ オフライン準備完了（次からは通信なしでも使えます）
ここに画像を貼り付け／ドロップ
パソコン: Ctrl+V で貼り付け、または画像ファイルをドラッグ
スマホ: 下のボタンから写真を選んでください
画像を待っています…
うまく読めないとき
  • QRコードの部分だけを切り抜いた画像で試す（周りの余白が大きいと失敗しやすい）
  • スクリーンショットは、QRコードが大きく写っている状態で撮る
  • 暗い・ぼやけた写真は、明るい場所で撮り直すか、元のQR表示をスクリーンショットする
  • 白黒が反転したQR（黒背景に白など）にも対応しています
iPhoneでアプリのように使う方法
  1. このページを Safari で開く
  2. 共有ボタン（□に↑）をタップ
  3. 「ホーム画面に追加」を選ぶ

ホーム画面のアイコンから、普通のアプリのように全画面で開けるようになります。追加したあと、ホーム画面のアイコンから一度オンラインで開くと、以後はオフラインでも読み取り機能が動きます（画面に「オフライン準備完了」が出れば準備OKです）。

読み取りエンジン: zxing-wasm（ZXing-C++ / Apache-2.0・MIT）と jsQR（Apache-2.0）、対応ブラウザでは標準の BarcodeDetector も併用します。同梱ライブラリのライセンスは THIRD-PARTY.md にまとめています。
参考実装: html5-qrcode 系の「ファイル読み取りは端末内で完結する」方式。自前ホスト版（GitHub Pages）。
